# Memorin 数据结构重构方案 - 完善版

> **重构日期**: 2025-01-18  
> **重构版本**: v2.1  
> **重构范围**: 知识管理 + 复习系统 + 数据存储  
> **重构目标**: 解决数据结构矛盾，提升系统性能和可维护性

## 🎯 重构目标

### 解决的核心问题
1. ❌ **分类系统冗余**: `category` 字段与三级结构重叠
2. ❌ **数据混合存储**: 知识内容与复习数据耦合
3. ❌ **时间格式不统一**: ISO字符串 vs 时间戳混用
4. ❌ **关联关系复杂**: 需要复杂修复逻辑的数据关联
5. ❌ **存储策略矛盾**: 双向关联与单向关联并存
6. ❌ **题型设计耦合**: 不同题型字段混合在同一实体中

### 重构原则
- ✅ **单一职责**: 每个实体只负责一类数据
- ✅ **数据一致性**: 统一的字段类型和命名规范
- ✅ **关联简化**: 清晰的外键关系，避免冗余
- ✅ **性能优化**: 便于查询和索引的数据结构
- ✅ **扩展性**: 支持未来功能扩展的灵活设计
- ✅ **题型解耦**: 不同题型完全独立存储和管理

## 📊 重构后的数据结构设计

### 1. 知识分类系统 (Category)

```typescript
/**
 * 知识分类实体 - 统一的层级分类系统
 * 替代原有的 KnowledgeBase + KnowledgeArea 双层结构
 * 支持无限层级，推荐使用3级：学科（知识库） → 章节（知识区） → 小节（子知识区）
 */
interface Category {
  /** 分类唯一标识符 */
  id: string
  
  /** 分类名称 - 用于显示 */
  name: string
  
  /** 父分类ID - null表示顶级分类 */
  parentId: string | null
  
  /** 分类层级 - 1:学科级, 2:章节级, 3:小节级, 4+:自定义 */
  level: number
  
  /** 完整分类路径 - 如"数学/高等数学/极限理论" */
  path: string
  
  /** 分类描述 - 可选的详细说明 */
  description?: string
  
  /** UI显示颜色 - hex格式，如"#667eea" */
  color: string
  
  /** UI显示图标 - emoji或图标类名 */
  icon: string
  
  /** 同级排序权重 - 数值越小越靠前 */
  sortOrder: number
  
  /** 是否激活 - 支持软删除 */
  isActive: boolean
  
  /** 关联用户ID - 多用户支持 */
  userId: string
  
  /** 创建时间戳 */
  createdAt: number
  
  /** 更新时间戳 */
  updatedAt: number
}
```

  /** 正则表达式模式 */
  regexPattern?: string
  
  /** 评分要点(问答题) */
  scoringPoints?: ScoringPoint[]

  maxWordCount?: number
  
  /** 最小字数要求 */
  minWordCount?: number
  
  /** 创建时间戳 */
  createdAt: number
  
  /** 更新时间戳 */
  updatedAt: number
}

 * 评分要点(问答题使用)

### 3. 复习进度 (ReviewProgress)

```typescript
/**
 * 复习进度实体 - SM-2算法的核心数据
 * 与Knowledge分离，避免编辑知识点时影响复习数据

interface ReviewProgress {
  /** 复习记录唯一标识符 */
  id: string
  
  /** 关联的知识点ID - 外键 */
  knowledgeId: string
  
  /** 总复习次数 - 包括答对和答错 */
  reviewCount: number
  
  /** 答对次数 - 用于计算正确率 */
  correctCount: number
  
  /** 上次复习时间戳 - 0表示从未复习 */
  lastReviewed: number
  
  /** 下次复习时间戳 - SM-2算法计算结果 */
  nextReview: number
  
  /** 当前复习间隔天数 - SM-2算法核心参数 */
  interval: number
  
  /** 遗忘难度系数 - 范围1.3-3.0，越高越容易记住 */
  easeFactor: number
  
  /** 连续答对次数 - 用于激励和成就系统 */
  streak: number
  
  /** 复习状态 - new:新建 learning:学习中 graduated:已掌握 */
  status: 'new' | 'learning' | 'graduated'
  
  /** 关联用户ID */
  userId: string
  
  /** 创建时间戳 */
  createdAt: number
  
  /** 更新时间戳 */
  updatedAt: number
}
```

interface StudySession {

  // exam: 自定义测试会话

  targetCategoryId?: string

  sessionConfig: {
    /** 目标复习数量 */
    targetCount?: number
    /** 时间限制(分钟) */
    timeLimit?: number
    /** 难度范围 */
    difficultyRange?: [number, number]
  }
  
  /** 关联用户ID */
  userId: string
  
  /** 创建时间戳 */
  createdAt: number
}

## 🔗 实体关联关系

### 数据关联图
```
User (用户)
├── Category (1:N) ──────────── Knowledge (1:N)
│   └── (层级自关联)               │
│                                  ├── ReviewProgress (1:1)
│                                  ├── ReviewRecord (1:N)
│                                  └── Mistake (0:1)
├── StudySession (1:N) ─────────── ReviewRecord (1:N)
├── UserSettings (1:1)
└── LearningStatistics (1:N)
```

### 外键约束关系
```sql
-- Knowledge相关外键
Knowledge.categoryId → Category.id
Knowledge.userId → User.id

-- 题型数据外键
TextQuestionData.knowledgeId → Knowledge.id
ChoiceQuestionData.knowledgeId → Knowledge.id
CodeQuestionData.knowledgeId → Knowledge.id

-- ReviewProgress外键
ReviewProgress.knowledgeId → Knowledge.id
ReviewProgress.userId → User.id

-- ReviewRecord外键
ReviewRecord.knowledgeId → Knowledge.id
ReviewRecord.sessionId → StudySession.id

-- Mistake外键
Mistake.knowledgeId → Knowledge.id
Mistake.userId → User.id

-- StudySession外键
StudySession.userId → User.id
StudySession.targetCategoryId → Category.id (nullable)

-- Category自关联
Category.parentId → Category.id (nullable)
```
